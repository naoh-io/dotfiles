# dotfiles

My CachyOS desktop: a dark, near-black setup with lilac and pink accents, built on **Hyprland** and the **Noctalia** shell.

## What's inside

| Folder | What it configures |
|---|---|
| `hypr/` | Hyprland (0.56, **Lua config**): keybinds, window rules, borders, animations, monitors |
| `noctalia/` | Noctalia shell: bar, panels, wallpaper and appearance settings |
| `kitty/` | kitty terminal |
| `fish/` | fish shell |

## My setup

- **OS:** CachyOS
- **Compositor:** Hyprland 0.56 (configured in Lua, not the classic `hyprland.conf`)
- **Shell / bar:** [Noctalia](https://docs.noctalia.dev)
- **Terminal:** kitty
- **Shell:** fish
- **Cursor:** Bibata-Modern-Ice
- **UI font:** SF Pro Text (not included, see below)
- **Palette:** lilac `#c3c0ff`, periwinkle `#a9b1ff`, pink `#e6b8d8` / `#f0cce4`, salmon `#ffb4a8`

## Requirements

Install these first (names may vary slightly by distro):

```bash
sudo pacman -S hyprland kitty fish fastfetch
paru -S bibata-cursor-theme
```

Noctalia has its own install steps, follow the [Noctalia docs](https://docs.noctalia.dev).

## Install

**Back up your current config first.** These commands replace your existing folders.

```bash
git clone https://github.com/naoh-io/dotfiles.git ~/dotfiles
cd ~/dotfiles

for d in hypr noctalia kitty fish; do
  [ -e ~/.config/$d ] && mv ~/.config/$d ~/.config/$d.bak
  cp -r $d ~/.config/$d
done
```

Then log out and back in.

## Things you will want to change

- **`hypr/config/monitors.lua`**: resolution and scale are set for my 15" 1920x1080 laptop screen.
- **`hypr/config/inputs.lua`**: keyboard layout and touchpad settings are mine.
- **Wallpaper**: Noctalia stores a path to my wallpaper folder. Set your own in Noctalia → Settings → Wallpaper.
- **Window border colors**: `hypr/config/decorations.lua`, in `active_border`.

## Fonts

The UI font is **SF Pro Text**, which is Apple's and can't be redistributed, so it isn't in this repo. Any clean sans-serif works. [Inter](https://rsms.me/inter/) looks very similar. Install fonts to `~/.local/share/fonts/`, run `fc-cache -fv`, then set the name in Noctalia → Settings → Appearance → Font Family.

## Notes

- `kitty/themes/noctalia.conf` is generated by Noctalia and is ignored by git. Run Noctalia once and it will be created.
- Parts of `hypr/config/` started from CachyOS's default Hyprland configuration.
